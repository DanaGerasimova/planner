# Astrology Planner

A Django web application for generating personalized astrological forecasts.

## Tech Stack

Python, Django, PostgreSQL, Celery, Redis, Celery Beat, Docker, Nginx, Kerykeion, Gemini API.

## Features

- Custom user authentication and permissions
- Personalized forecast generation
- Asynchronous tasks with Celery and Redis
- Scheduled forecasts with Celery Beat
- Kerykeion and Gemini API integration
- Dockerized deployment with Nginx
